# Services

- API Gateway: public API, auth verification, response normalization
- Auth Service: users, passwords, JWTs, refresh tokens
- School Service: schools, classrooms, subjects, enrollments, join codes
- Lesson Service: lesson packs, versions, visibility, access codes
- AI Service: Gemma/Gemini, Ollama, local hub, deterministic mock runtime
- Assignment Service: assignments and progress
- Commons Service: public library, search, forks, reports
- Review Service: moderation queue and decisions
- Sync Service: offline push/pull and conflict handling
- Export Service: Markdown, PDF, `.kvpack`
- Notification Service: in-app notifications and push-token support
- Storage Service: object metadata and local/MinIO/S3 driver boundary
- Worker: event consumer and scheduled job host
